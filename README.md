The Budget Tracker App is an Android personal finance application built with Kotlin and Room Database. Users can sign up, log in, track expenses, create savings goals, and earn XP through a gamification system that rewards good financial habits. Each expense and goal displays in South African Rand (R), and users level up every 100 XP earned. The app features Material Design components including RecyclerView, MaterialCardView, FloatingActionButton, and LinearProgressIndicator. Built with MVVM architecture and coroutines for real-time data updates.
